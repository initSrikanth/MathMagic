# Comparing Fractions — redesigned review lesson

One review-only prototype built from the existing production-v2 mathematical primitives and the previous experiment's FFmpeg scene composition. Published files and both earlier prototypes are preserved.

The seven-stage lesson establishes equal wholes and prior knowledge before notation, connects numerator/denominator to the model, guides predictions before explanations, and delays comparison signs until visual reasoning is established. Equal-numerator work explicitly corrects the bigger-denominator misconception. Equivalent-fraction subdivisions preserve shaded amounts. The thirds-versus-quarters challenge is guided extension, followed by a reflective recap. `storyboard.json` and `transcript.md` contain the complete instructional sequence; `timeline.json` records actual narration timing, native speaking rates and intentional thinking/processing intervals.

The existing local model inventory contains Kokoro v1.0 only. Runtime API inspection confirms this Kokoro implementation exposes speaker selection and speed/length control, without explicit emotion or emphasis conditioning. Generic reference-audio generation APIs are not evidence of Kokoro support for expressive reference conditioning. No larger replacement framework, paid service or voice cloning was introduced. **af_heart** (speaker 3, American English female) is retained as the starting candidate. Native synthesis rates vary modestly by teaching role (0.87–0.94); there is no audio stretching, pitch manipulation or artificial emotional filtering. Punctuation is not treated as proof of expressive narration.

**Voice limitation:** direct perceptual listening is unavailable, and this remains the same underlying voice as prototype A. Neither native pacing changes nor technical tests establish that its pale/flat delivery is solved. The reviewer must judge pronunciation, warmth, curiosity and teacher-like expressiveness. This is a completed instructional review candidate, not a claim of perceptually certified premium voice quality.

`produce.py` reuses the current CPU stack (Pillow, NumPy, soundfile, sherpa-onnx 1.12.26, FFmpeg/FFprobe), with existing Kokoro weights under `/workspace/work/kokoro-multi-lang-v1_0`; intermediates stay under `/workspace/work/comparing-redesign-render`. No weights are committed. Run with `PYTHONPATH=/workspace/work/premium-audio-tools`. `qa.py` performs focused exact arithmetic, final-model pixel checks, shade-preserving animation checks, measured cue/pause checks, complete decode, format, clipping, audible-segment and unexpected-silence checks. No broad website tests are required for this isolated review file. VTT captions are narration segments, not word-aligned subtitles.
