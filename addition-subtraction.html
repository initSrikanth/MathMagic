Efficient Mental Strategies

Good mathematicians choose a strategy that fits the numbers.

KEY IDEA

Addition and subtraction are related. Use place value, partitioning, compensation and friendly numbers instead of always reaching for a written algorithm.

Worked example — compensation

Calculate 4,798 + 2,356.

4,798 + 2 = 4,800
2,356 − 2 = 2,354
4,800 + 2,354 = 7,154

We moved 2 from one addend to the other. The total stayed the same.

Worked example — count up for subtraction

Calculate 8,003 − 7,986.

7,986 → 8,000 is +14
8,000 → 8,003 is +3
14 + 3 = 17

Quick practice

Use a friendly-number strategy: 2,999 + 1,426

Think about it

Why might counting up be more efficient for 6,004 − 5,997 than using a long written subtraction?

Show explanation

The numbers are very close. The difference can be found quickly by counting 3 to 6,000 and another 4 to 6,004, giving 7.

Accurate Written Addition & Subtraction

Place-value alignment keeps each digit in the correct column.

STEPS

1. Align ones under ones, tens under tens, and so on. 2. Work from right to left. 3. Regroup when a place has too many or too few units. 4. Check the result.

Worked example — addition

38,746+ 27,58966,335

6 + 9 = 15, so write 5 ones and regroup 1 ten. Continue through each place-value column.

Worked example — subtraction with regrouping

70,204− 38,65731,547

Regroup across the zero places carefully. Each regrouping changes the value in neighbouring columns but not the total number.

Quick practice

Calculate 46,728 + 18,695.

Think about it

In 52,000 − 27,684, why can we not simply subtract 7 from the 2 in the thousands column?

Show explanation

Each column represents a different place value. Regrouping must preserve the value of 52,000 before the digits can be subtracted correctly.

PAGE 3

Estimate & Check Reasonableness

An estimate tells us whether an exact answer makes sense.

KEY IDEA

Round numbers to useful place values before calculating. Your estimate does not replace the exact answer — it is a powerful check.

Worked example

Estimate 48,721 + 31,406.

48,721 ≈ 50,000
31,406 ≈ 30,000
Estimated total ≈ 80,000

The exact answer, 80,127, is close to the estimate, so it is reasonable.

Detect an error

A calculator display says 62,480 − 19,760 = 427,200.

62,000 − 20,000 ≈ 42,000. An answer over 400,000 cannot be reasonable.

Quick practice

Estimate 73,850 − 21,920 by rounding both numbers to the nearest ten thousand.

Think about it

Two students estimate the same calculation differently. Can both estimates be useful?

Show explanation

Yes. Different sensible rounding choices can give different estimates. The purpose is to produce a nearby benchmark that helps judge whether an exact result is reasonable.

Missing Values & Inverse Operations

Use the relationship between addition and subtraction to find an unknown.

INVERSE RELATIONSHIP

If 3,475 + 2,860 = 6,335, then 6,335 − 2,860 = 3,475 and 6,335 − 3,475 = 2,860.

Worked example

Find the missing value: □ + 4,875 = 12,300

12,300 − 4,875 = 7,425
Check: 7,425 + 4,875 = 12,300.

Unknown subtrahend

15,000 − □ = 8,650

15,000 − 8,650 = 6,350
So 15,000 − 6,350 = 8,650.

Quick practice

Find □: □ + 3,680 = 9,250

Think about it

Why is subtraction useful for checking an addition calculation?

Show explanation

Subtraction reverses addition. If subtracting one addend from the total gives the other addend, the relationship is consistent.

PAGE 5

Model Practical Problems

Understand the situation before choosing an operation.

MODEL THE PROBLEM

1. Identify what is known and unknown. 2. Decide whether quantities are being combined, increased, decreased or compared. 3. Write a number sentence. 4. Calculate efficiently. 5. Interpret and check the answer in context.

Worked problem

A community fundraiser has a target of $25,000. It has already raised $17,685. How much more is needed?

25,000 − 17,685 = 7,315
The fundraiser needs $7,315 more.

Two-step problem

A library had 18,450 books. It received 2,375 new books and removed 1,268 damaged books. How many books does it have now?

18,450 + 2,375 = 20,825
20,825 − 1,268 = 19,557 books.

Quick practice

A school needs $12,000 for equipment. It has $7,850. How much more does it need?

Think about it

A problem contains the word “more”. Does that always mean you should add?

Show explanation

No. “How much more is needed?” asks for a difference, so subtraction may be required. Choose the operation from the relationship between the quantities, not from a single keyword.
