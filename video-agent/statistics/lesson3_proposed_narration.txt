Two classes both have a mode of two library books. Must their borrowing patterns look the same? Imagine each pupil placing one counter above the number of library books they borrowed. As counters gather into stacks, some numbers may be more common than others. Before naming a most common value, look at the whole arrangement. What story might those stacks tell about the class?

Today we are learning to describe the mode and shape of a data distribution in context. Our goal is to describe the mode and the whole distribution in context. We want to say what the most common value means, but also notice pupils whose values are different. A single summary is a useful clue, rather than the entire investigation.

I can identify the most frequent value or category. I can describe clusters, gaps and how frequencies are spread. I can compare two distributions using evidence. Remember that frequency means how often a value occurs. In a column graph, the horizontal labels name the book counts and the vertical scale counts pupils. Read both labels before giving an answer. Two books and three pupils describe different parts of the same display.

The mode is the value or category with the highest frequency, not the frequency itself. Two values can tie for the highest frequency. If all observed values occur equally often, there is no useful mode. A distribution shows how all the responses are spread. Describe where most values gather, any gaps and whether counts are balanced or trail to one side. Keep zero-frequency counts to show gaps. Build the first display one pupil at a time. Place one counter at zero books, one at one book, then three counters at two books. Finally place one at three and one at four. We can replace each stack by a column without changing its frequency. Now the concrete counters and the graph show the same data.

Books borrowed: 0, 1, 2, 2, 2, 3, 4. What is the mode, and what does it mean? Before hearing the answer, compare the column heights. Which book-count value belongs to the tallest column? Think about how you would finish this sentence: the most common number of books is something, because something pupils borrowed that many. Keep the value and its frequency separate.

Two books is the mode because three pupils borrowed two books. Most values gather around two; the frequencies on either side are balanced. The mode is 2 books, not 3 pupils. Count the three pupils at two books, then trace down to the label two. That label is the mode. One pupil borrowed zero, and another borrowed four, so it would be wrong to say everyone borrowed two. The distribution is balanced around two, with matching frequencies on the two sides.

Class A frequencies for 0,1,2,3,4 books: 1,2,5,2,1. Class B: 0,0,5,4,2. What stays the same? Now compare two classes with eleven pupils each. For zero through four books, Class A has frequencies one, two, five, two and one. Class B has zero, zero, five, four and two. Predict what the modes will share. Then decide whether the rest of the distributions must match.

Both have a mode of 2 books. A is balanced around 2. B has no pupils at 0 or 1 and all values are 2 to 4. A shared mode does not describe the whole distribution. If two bars tie at the top, report both modes. Class A has pupils on both sides of two books. Class B has no pupils at zero or one, and all its observations are two, three or four. Both classes have the same tallest value at two books. Their shared mode does not make the two sets of observations identical. Use the empty positions and the other column heights as evidence.

“The mode describes everyone.” It describes the most common value. Look at all the bars before making a claim about a group. Imagine one extra pupil reporting four books. The highest numerical value has changed in frequency, but that alone does not make four the mode. Compare all frequencies again. A mode is chosen by how often a value occurs, rather than by how large the value is.

A good report connects numbers to the people and the question. Which feature would you describe after giving the mode: a gap, a cluster, or how the values are spread? Use a specific book count and frequency to support your explanation, and remember to look at every part of the distribution.
