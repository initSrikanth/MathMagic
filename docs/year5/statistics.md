# Data Detectives — Statistics (Year 5)

Internal curriculum/coverage record. Product title is configured in js/statistics-config.js.

## Verified scope (20 November 2026)
Primary ACARA v9 source: https://v8.australiancurriculum.edu.au/media/7564/classroom_ideas_5-8_microbit_environmental_measurement_with_v84_and_v9_content.pdf (final v9 content, not the earlier review draft).
Cross-check: QCAA Year 5 alignment https://www.qcaa.qld.edu.au/downloads/aciqv9/mathematics/curriculum/ac9_maths_yr5_as_cd_alignment.pdf.

Paraphrased requirements:
- AC9M5ST01: acquire, validate and represent nominal/ordinal categorical and discrete numerical data for a purpose with software including spreadsheets; report mode and distribution shape in context.
- AC9M5ST02: interpret line graphs of change over time, relationships and supported conclusions.
- AC9M5ST03: pose a question/problem, plan and collect relevant data, choose displays, interpret and communicate contextual findings.

No mean/median, probability or formal secondary-level distribution terminology is assessed. Mode is a category/value, not its frequency. Tied highest frequencies have multiple modes; when every observed value occurs equally often we use “no useful mode”. Numerical gaps retain zero-frequency entries. Line graphs use equally spaced times and labelled scales.

## Teaching sequence and assessment matrix (established before coding)
All wording and visuals are original. Five lessons: L1 questions/types/fair collection; L2 validate and tabulate with a digital data editor and spreadsheet formula example; L3 frequency/mode/distribution; L4 line graphs; L5 full investigation/report/limitations.

| Band (five each) | Families | Lessons / codes |

| Foundation | nominal, ordinal, discrete, read-frequency, read-time | 1,2,4 / ST01,ST02 |

| Developing+ | validation, missing-frequency, tied-modes, shape, line-interval | 2,3,4 / ST01,ST02 |
| Proficient | fair-question, sample, display, compare-lines, unsupported-forecast | 1,4,5 / ST02,ST03 |
| Application | collection-plan, record-check, context-conclusion, ordinal-order, zero-frequency | 1,2,3,5 / ST01,ST03 |
| Challenge | mode-update, compare-distributions, misleading-scale, investigation-report, investigate-next | 3,4,5 / ST01,ST02,ST03 |
