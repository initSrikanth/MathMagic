## Production reference and implementation gaps
Remote main contains `videos/MathMagic_Mixed_Numbers_FINAL.mp4`, Git blob `d1776a45b7768b6a35532a4a71812581f5abcf8c`, 4,870,811 bytes. The approved publication record specifies SHA-256 `92c831fce1d463b7a369511098a1a5eff47a8756d840e5fe52f510dc3f7cdc56`, 75.889 seconds, 1280×720 H.264/yuv420p and stereo 48 kHz AAC. These technical details are from that record; this audit did not re-download or re-hash the bytes. Preserve this final unchanged. Future outputs require 1920×1080; upscaling this approved file is not part of this task.

The `feature/video-production-agent` branch contains `agent.py`, `produce_mixed.py`, `production.py`, requirements, lesson definitions and tests. Main contains production rules but not that complete implementation. Inspected Mixed Numbers source defines a 1920×1080 board: left teacher lane about x=0–320, board x=330/y=55, beige wall and brown floor at y=875. Reuse that design after comparing actual approved frames.

Do not run those scripts as a finished production pipeline:
- `produce_mixed.py` uses weighted estimated scene durations, not the approved carefully timed cue sheet. It renders boards at 1280×720. Several positional `bar(..., 360)`/`bar(..., 350)` calls bind the denominator rather than the apparent intended width, requiring review before reuse.
- `production.py` scales/exports and checks 1280×720; it needs a scoped 1080p update. Alpha cropping samples one frame and does not certify moving-frame bounds.
- The legacy provider client uses POST /v1/video.webm and pose IDs; current connected avatar tooling uses look IDs and different parameters. Do not assume those IDs or endpoints are interchangeable or that transparent output is entitled.
- The older README contains historical unapproved-avatar/mouth-test and five-lesson batch-publication steps. The user's approved final and canonical instructions govern this task: no new teacher, auditions, batch replacement or automatic paid run.
- `produce_comparing.py` contains slash notation in some number-line/summary labels. Do not reuse those labels in final graphics; all fractions must render stacked.
- Existing publish-fractions workflow checks out that feature branch and targets Comparing Fractions. It is not a generic Mixed Numbers publisher and was not run.
